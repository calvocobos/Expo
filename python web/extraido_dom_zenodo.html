Desarrollo de un sistema de información web para la administración de los procesos de registro, atención, inventario y finanzas del consultorio odontológico Lalysdent del distrito de Cusco

Creators

  • Cobos Vargas, Irvin Julian (Producer)1
  • Calvo Arteaga, Carlos Antonio (Producer)1
  • 1. Universidad Andina del Cusco

Description

La presente tesis tiene como objetivo principal el desarrollo de un sistema de información web para la administración de los procesos de registro, atención, inventario y finanzas del consultorio odontológico LALYSDENT de la ciudad del Cusco. Se utilizó metodología ágil Scrum y arquitectura MVC, implementando módulos para registro de pacientes, gestión de citas, administración de tratamientos, inventario y reportes consolidados, con tecnologías como Laravel 11, Jetstream, Livewire, Tailwind CSS, JQuery y MySQL. El sistema contribuye a la digitalización y mejora de la eficiencia administrativa. https://hdl.handle.net/20.500.12557/8558

Methods

El desarrollo del proyecto siguió la metodología ágil Scrum, permitiendo un avance iterativo, retroalimentación continua y entregas incrementales.

La arquitectura del software se basó en el patrón Modelo–Vista–Controlador (MVC), separando la lógica de negocio, la interfaz de usuario y el control del flujo, lo que mejora la mantenibilidad y escalabilidad del sistema.

Technical info

Información técnica

El proyecto fue desarrollado utilizando Laravel 11 como framework backend, basado en la arquitectura Modelo–Vista–Controlador (MVC).

La capa de presentación se implementó con Tailwind CSS, JavaScript, CSS y jQuery, permitiendo una interfaz de usuario responsiva e interactiva.

Para la gestión de autenticación y scaffolding se utilizó Laravel Jetstream.

El proceso de construcción y empaquetado de recursos frontend se realizó mediante Vite.

El control de versiones y la gestión del código fuente se llevaron a cabo utilizando Git y GitHub.

Abstract (English)

English Tittle:

Development of a web information system for the administration of the registration, care, inventory and finance processes of the Lalysdent dental office in the district of Cusco.

Abstract (English)

This thesis aims to develop a web-based information system for managing registration, care, inventory, and financial processes at the LALYSDENT dental office in Cusco. Agile Scrum methodology and MVC architecture were used, with modules for patient registration, appointment management, treatment administration, inventory control, and consolidated reports, implemented with Laravel 11, Jetstream, Livewire, Tailwind CSS, JQuery, and MySQL. The system contributes to digitalization and improved administrative efficiency.

Целью данной работы является разработка веб-ориентированной информационной системы для управления регистрацией, обслуживанием пациентов, складским учетом и финансовыми процессами в стоматологической клинике «Лалисдент» в городе Куско. Система способствует цифровизации и повышению эффективности административной работы.
